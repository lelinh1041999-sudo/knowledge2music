# knowledge2music

学習内容をAIで要約し、歌詞を作成して、複数の音楽生成サービスから選んで曲を作るStreamlitアプリです。授業での発表を目的としたプロトタイプです。

## Windowsでの起動方法

プロジェクトフォルダーでPowerShellを開き、次のコマンドを実行します。

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

`.streamlit/secrets.toml` がない場合は、サンプルから作成します。

```powershell
Copy-Item .streamlit\secrets.example.toml .streamlit\secrets.toml
```

`secrets.toml` に Gemini APIキーを設定してください。fal.aiのモデルを使う場合は、[fal.aiのダッシュボード](https://fal.ai/dashboard/keys)でAPIキーを作成し、利用可能なクレジットを用意して `FAL_KEY` に設定します。ローカルモデルを使う場合は、ACE-Step APIサーバーを別途起動してください。認証を有効にしたローカルサーバーでは `ACESTEP_LOCAL_API_KEY` も設定します。secretsファイルやAPIキーを共有したり、スライドやソースコードに掲載したりしないでください。

アプリを起動します。

```powershell
.venv\Scripts\python.exe -m streamlit run app.py
```

## デモの流れ

1. 言語で「日本語」を選びます。
2. Google OAuthが未設定の場合、デモ用メールアドレスは入力済みです。ボタンを押して進みます。Googleアカウントの本人確認は行いません。
3. 「サンプルで試す」を押すと、APIキーや通信なしで要約・歌詞の例が表示されます。この例では音声は生成しません。
4. 自分の教材を使う場合は、サイドバーの「APIキー」に自分のGemini APIキーを入力し、教材を入力・アップロードして生成します。
5. 「曲を生成」で、選んだサービスを使って音声を作ります。fal.aiには自分のAPIキーと利用可能なクレジットが必要です。サービスの料金・利用条件を確認してから生成してください。
6. 完了した曲はアプリ内で再生またはダウンロードできます。「歌詞動画を作成」を押すと、その音声を再利用してMP4を作成します。音声がまだない場合は、選択したサービスで曲を作ってから動画を作成します。
7. 必要に応じて、手元のMP3/WAVファイルをライブラリに追加します。

音楽ジャンルにはJロック、V-Pop、メタル、ジャズ、ボレロ、映画音楽などがあり、「ジャンルを自由入力」から自分のジャンルも指定できます。

要約・作詞には `gemini-4-hydrogen` を使用し、応答を取得できない場合は `gemini-3.5-flash-lite` を試します。実際に使用したモデル名は生成結果に表示します。両モデルには[Gemini APIの無料枠](https://aistudio.google.com/docs/pricing#gemini-4-hydrogen)があります。

## Chromebook・ブラウザーで使う場合

このアプリはStreamlit Community Cloudに配置できます。GitHubの公開リポジトリを接続し、app.pyを指定して公開すると、Chromebookからブラウザーで開けます。ローカルPCのlocalhost URLはChromebookから利用できません。

公開デモはAPIキーなしでサンプルを表示できます。教材から要約・歌詞を作るにはGemini APIキー、音声を生成するにはfal.ai APIキーと利用可能なクレジットが必要です。サイドバーから入力したキーはアプリのサーバーを経由して各サービスに送信され、ファイルには保存されません。利用料は入力したキーの所有者に請求されます。共有の公開アプリに管理者のキーを設定すると、第三者の利用分も管理者に請求されるため、設定しないでください。

## 音楽生成サービス

| 選択肢 | 料金・必要なもの | 長所 | 短所 |
|---|---|---|---|
| ACE-Step（fal.ai） | 約**$0.0002/秒**（60秒で約**$0.012**）。`FAL_KEY` とクレジットが必要。 | 低価格で試しやすく、生成時間を指定できる。 | 歌声の明瞭さや歌詞の再現にばらつきがある。 |
| MiniMax Music 3.0（fal.ai） | 約**$0.002/秒**（60秒で約**$0.12**）。`FAL_KEY` とクレジットが必要。 | 歌詞とスタイルを別々に指定し、アプリでは最長60秒の曲を生成できる。 | 長い歌詞は途中で切れる場合がある。送信できる歌詞は3,500文字まで。ベトナム語の発音は未確認。 |
| Mureka V8（fal.ai） | 歌詞を指定すると**$0.045/曲**。歌詞は最大5,000文字。`FAL_KEY` とクレジットが必要。 | 歌詞専用入力があり、日本語を含む複数言語に対応。 | 公式の対応言語一覧にベトナム語がないため、ベトナム語の発音は未確認。 |
| Google Lyria 3.5（fal.ai） | **$0.10/回**。`FAL_KEY` とクレジットが必要。 | 数分の構成付きフル曲を生成でき、日本語に対応。 | 歌詞はプロンプト経由で渡すため、元の歌詞と完全一致するとは限らない。ベトナム語は公式対応言語一覧にない。 |
| ACE-Step（ローカルAPI） | 生成ごとのAPI料金なし。ACE-Step 1.5 APIサーバーを別途インストールして起動する。PCの性能・電力・設定作業が必要。 | fal.aiの従量課金を使わず、自分のPC上で生成できる。 | 初期設定と対応するPCが必要。速度や歌声品質はPC性能・モデルに左右される。 |

fal.aiの4モデルは同じ `FAL_KEY` とアカウント残高を使います。表示価格や対応言語は変更される場合があるため、利用前に[ACE-Step](https://fal.ai/models/fal-ai/ace-step)、[MiniMax Music 3.0](https://fal.ai/models/minimax/music-3)、[Mureka V8](https://fal.ai/models/mureka/v8/generate/song)、[Google Lyria 3.5](https://fal.ai/models/google/lyria-3.5)の各ページを確認してください。[Mureka公式FAQ](https://platform.mureka.ai/docs/en/faq.html)と[Lyria 3.5のモデル資料](https://fal.ai/models/google/lyria-3.5/api)では日本語対応が確認できますが、ベトナム語は両モデルの公開対応言語一覧にありません。料金は成功した生成ごとに発生するため、選択肢の説明を確認してから実行してください。

ローカル版の導入は[ACE-Step 1.5公式ガイド](https://github.com/ace-step/ACE-Step-1.5/blob/main/docs/en/INSTALL.md)を参照してください。公式ガイドではPython 3.11–3.12、VRAM 4GB以上（LM使用時6GB以上）、モデル用に約10GBの空き容量が目安です。CPUのみでも動作しますが、大幅に遅くなる場合があります。クラウドにアプリを配置した場合、`127.0.0.1` は利用者のPCではなくアプリのサーバーを指します。

生成前にアプリ内の説明を確認してください。学習資料は要約・作詞のためGemini APIに送信され、音楽生成サービスには生成済みのタイトル、音楽スタイル、歌詞を送信します。ローカル版ではAPIキーを`.streamlit/secrets.toml`に設定できます。公開版ではサイドバーに自分のキーを入力できます。キーはアプリサーバーのセッションメモリで使われてファイル保存されませんが、各サービスへはアプリサーバーを経由して送信されます。利用料はキーの所有者に請求されます。共有の公開アプリに管理者キーを設定しないでください。

ベトナム語の歌詞は、モデルや歌詞によって発音が不明瞭になる場合があります。聞き取りやすさを重視する場合は、別のサービスの結果も確認してください。ローカルACE-Step APIにはベトナム語の言語指定を送りますが、発音の明瞭さを保証するものではありません。

## 歌詞動画

- 「歌詞動画の設定」でテーマカラーを選び、任意で背景画像を追加できます。曲の音に合わせて動く波形も表示できます。FFmpegで合成したMP4をアプリ内で再生・ダウンロードできます。
- AI動画では全体の指示に加え、`Verse: 暗い教室で論理回路がゆっくり光る`、`Chorus: 青い光が回路全体を走る`のように区間別に指示できます。最大3種類の短い映像を該当する区間で繰り返します。指示と曲のジャンル・雰囲気を公開の[Hugging Face Space](https://huggingface.co/spaces/Lightricks/LTX-2.5)に送ります。共有GPUの無料枠や混雑で映像を作れない区間にはテーマ背景を使います。
- 「動画に歌詞を表示」で歌詞のオン・オフを選べます。表示時刻は目安です。「歌詞と表示時刻を調整」で修正し、「歌詞動画を作成」を押し直してください。映像の切り替えも調整後の時刻に従います。同じ曲の動画を作り直す場合は音声を再利用します。
- Windowsでは `pip install -r requirements.txt` でFFmpegを含むパッケージを導入できます。Streamlit Community Cloudでは `packages.txt` で動画用フォントを導入します。

## 生成した曲の著作権

- fal.aiの4モデルには「Commercial use」の表示があります。[fal.aiの利用規約](https://fal.ai/legal/terms-of-service)では、生成物の独自性や第三者の権利を侵害しないことは保証されません。[ACE-Step 1.5の公式モデルカード](https://huggingface.co/ACE-Step/Ace-Step1.5)にはMITライセンスと生成曲の商用利用が記載されています。ローカルで生成した曲についても、既存曲との類似は個別に確認してください。
- 入力には自作の歌詞など、利用できるものを使ってください。曲を公開・配布・商用利用する前に、選択したモデルの最新の利用条件を確認し、既存曲のメロディーや歌詞によく似ていないか聴いてください。よく似た曲がある場合は、そのまま使うことを避け、利用する場合は必要な許諾を確認してください。[文化庁「AIと著作権について」](https://www.bunka.go.jp/seisaku/chosakuken/aiandcopyright.html)
